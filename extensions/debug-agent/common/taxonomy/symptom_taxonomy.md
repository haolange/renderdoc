# 症状分类学 (Symptom Taxonomy)

## 视觉症状

### 颜色异常
| 症状标签 | 描述 | 可能的不变量 |
|-----------|------|-------------|
| 黑色像素 | 渲染输出全黑 | I-NAN-01, I-LIGHT-UNPACK-01 |
| 白色像素 | 渲染输出全白 | I-NAN-01 |
| 白色斑点 | 局部白点闪烁 | I-NAN-01 |
| 颜色失真 | 颜色与预期不符 | I-COLOR-01 |
| 画面偏暗 | 整体亮度不足 | I-COLOR-01 |
| 画面过亮 | 整体亮度过度 | I-COLOR-01 |

### 几何异常
| 症状标签 | 描述 | 可能的不变量 |
|-----------|------|-------------|
| 物体消失 | 可见物体不显示 | I-GEO-01 |
| 背面剔除错误 | 背面应该显示但被剔除 | I-GEO-01 |
| 镜像消失 | 镜像物体不显示 | I-GEO-01 |
| 裁剪错误 | 物体被错误裁剪 | I-GEO-01 |

### 纹理异常
| 症状标签 | 描述 | 可能的不变量 |
|-----------|------|-------------|
| 纹理缺失 | 纹理未正确显示 | I-TEX-01 |
| 纹理扭曲 | UV映射错误 | I-TEX-01 |
| Mipmap问题 | 远处纹理模糊或闪烁 | I-MIP-01 |

### 深度异常
| 症状标签 | 描述 | 可能的不变量 |
|-----------|------|-------------|
| Z-fighting | 深度冲突闪烁 | I-DEPTH-01 |
| 深度精度问题 | 深度值异常 | I-DEPTH-01 |
| 遮挡错误 | 遮挡关系错误 | I-DEPTH-01 |

### 光照异常
| 症状标签 | 描述 | 可能的不变量 |
|-----------|------|-------------|
| 光照缺失 | 应该有光照的区域无光照 | I-SHADING-NONNEG-01 |
| 光照过强 | 光照强度异常高 | I-PREC-01 |
| 阴影缺失 | 应该有阴影的区域无阴影 | I-SHADING-NONNEG-01 |

## 性能症状

| 症状标签 | 描述 |
|-----------|------|
| 帧率骤降 | 帧率突然下降 |
| 卡顿 | 渲染卡顿 |
| 显存爆炸 | 显存使用量异常 |
| 加载缓慢 | 资源加载时间过长 |
