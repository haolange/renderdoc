## SSOT Sync and Drift Gate

Platform prompts are generated from `common/agents/*.md`.

1. Edit only `common/agents/*.md`.
2. Run sync command:

```bash
python extensions/debug-agent/scripts/sync_platform_agents.py
```

3. Run strict contract validation:

```bash
python extensions/debug-agent/scripts/validate_tool_contract.py --strict
```

Any non-zero result blocks finalization (tool-name drift, param drift, or missing `session_id` in examples).
